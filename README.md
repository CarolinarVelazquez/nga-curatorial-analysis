# Reading Curatorial Identity Through Open Data
### A Data Analysis of the National Gallery of Art Collection

Museums present themselves as guardians of art history.
But every collection is also a cultural argument — shaped by
geography, patronage, and the values of its time.

This project uses the NGA's public dataset to uncover three layers
of curatorial identity through data analysis.

## Findings
- **Finding 1** — The NGA organizes by curatorial school with a chronological progression
- **Finding 2** — Cross-school artistic influence is documented in the data but invisible on the gallery floor
- **Finding 3** — Private American collectors fundamentally shaped the collection
